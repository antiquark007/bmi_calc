## Frontend Improvements

The frontend of the BMI Calculator has been significantly improved to enhance user engagement and visual appeal. The following changes have been made:

- Added a header element with a title "BMI Calculator".
- Added a footer element with a message "Stay healthy!".
- Updated the form labels to be more descriptive.
- Added placeholder text to the input fields.
- Improved the styling of the form and input fields.
- Added hover effects to the button.

## New Features

The BMI Calculator now includes the following new features:

- Real-time BMI calculation as the user types.
- Dynamic feedback messages based on BMI value.
